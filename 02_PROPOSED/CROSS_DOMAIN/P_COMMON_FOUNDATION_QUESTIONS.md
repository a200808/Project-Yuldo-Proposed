# [P] 공통 기획 기반 구축 질문지

Status: [PROPOSED]
Owner: YULDO-AI-GENERAL
Purpose: 파트별 세션 분리 전에 공통 전제를 정리하고, 논의가 핵심 기획에서 벗어나는 것을 방지한다.
Canon Notice: 이 문서는 질문과 검토 항목만 제시한다. 답변이 작성되더라도 사용자 승인 전까지 [PROPOSED]이며, 공식 Canon을 변경하지 않는다.

## 사용 규칙

1. 현재 Phase의 핵심 질문에 직접 필요한 항목부터 답한다.
2. 질문 하나마다 답변 상태를 `[OPEN]`, `[PROPOSED]`, `[CONFIRMED]`, `[REVIEW]`, `[N/A]` 중 하나로 표시한다. `[CONFIRMED]` 표시는 사용자가 승인한 경우에만 사용한다.
3. 기존 Confirmed 문서에 답이 있으면 새로 결정하지 말고 원문을 링크한다.
4. Proposed 문서에만 답이 있다면 Canon으로 간주하지 않고, 필요 시 충돌·중복 여부를 검토한다.
5. 세부 수치, 개별 무기, 개별 퀘스트, 지역별 콘텐츠 등은 상위 방향을 결정하는 데 필수적이지 않으면 후속 담당 세션으로 넘긴다.
6. 질문의 답이 다른 질문의 선행 조건이라면 선행 질문부터 처리한다.
7. 새 아이디어가 이 질문지의 목적을 벗어나면 별도 Proposed로 기록하고, 현재 의사결정은 계속한다.

## 논의 이탈 방지 체크

새로운 주제나 아이디어가 나왔을 때 다음을 확인한다.

1. 이 주제는 현재 질문에 답하는 데 직접 필요한가?
2. 이 주제는 지금 Phase의 핵심 질문에 해당하는가?
3. 기존 Confirmed/Proposed 문서에 이미 답 또는 유사 제안이 있는가?
4. 이 결정은 다른 결정의 선행 조건인가?
5. 지금 다루지 않으면 다음 파트가 작업을 시작할 수 없는가?
6. 지금 다루지 않아도 된다면 어느 담당 세션으로 넘길 것인가?

위 질문 중 현재 의사결정과 직접 관련된 근거가 없으면, 아이디어를 별도 Proposed로 기록하거나 해당 파트로 이관하고 현재 논의로 돌아온다.

1. A — 프로젝트 목적과 플레이어 경험

7. G — 범위와 개발 현실성
