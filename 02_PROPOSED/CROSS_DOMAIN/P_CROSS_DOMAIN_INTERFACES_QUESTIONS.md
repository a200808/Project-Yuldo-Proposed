# [P] 파트 간 연결·의존성 질문지

Status: [PROPOSED]
Owner: YULDO-AI-GENERAL (coordination), all relevant specialist AIs, YULDO-AI-REVIEW (independent review)
Purpose: 각 파트의 문서가 따로는 성립해도 서로 연결할 때 모순되는 문제를 예방한다.
Canon Notice: 이 문서는 연결 질문과 제안만 기록한다. 연결 규칙은 사용자 승인 전까지 Canon이 아니다.

## 사용 규칙
- 한 파트가 소유하는 세부 내용과 여러 파트가 공유하는 인터페이스를 구분한다.
- 의존 관계를 선행 입력 → 처리 담당 → 산출물 → 소비 파트 → 실패/변경 시 영향으로 기록한다.
- Proposed 간 충돌은 원안을 보존하고 대안·반론을 별도로 기록한다.
- 관련 파트가 둘 이상이면 단일 담당자를 정해 검토를 조정하되, 타 파트의 전문 결정을 대신하지 않는다.

## A. 파트 경계와 소유권
- [OPEN] 각 공통 질문과 규칙의 최종 소유 문서는 무엇인가?
- [OPEN] WORLD, STORY, GAMEPLAY, EQUIPMENT, ALLIES, NPC, QUEST, CONTENT, REVIEW, GENERAL의 책임과 제외 범위는 어디까지인가?
- [OPEN] 여러 파트가 동시에 작성할 수 있는 내용과 단일 소유자가 작성해야 하는 내용은 무엇인가?
- [OPEN] 공통 설정과 영역별 세부 적용 규칙이 다를 경우 각각 어느 문서에 기록할 것인가?
- [OPEN] 두 파트가 같은 개념을 다르게 정의하면 어느 담당자가 조정하고 누가 승인하는가?

## B. 세계관 ↔ 스토리
- [OPEN] 세계관 규칙이 스토리 사건을 제한하는 지점은 무엇인가?
- [OPEN] 스토리에서 새로 필요한 현상·기술·도술은 기존 규칙으로 설명되는가, 새 Proposed가 필요한가?
- [OPEN] 주요 사건이 세계 상태, 지역 접근, 세력 관계, NPC 행동을 어떻게 바꾸는가?
- [OPEN] 역사적 인물·기관·지리와 창작 사건이 충돌할 때 어떤 자료와 검토를 거칠 것인가?
- [OPEN] 스토리의 필수 사건과 플레이어의 선택적 행동은 어떤 방식으로 양립하는가?

## C. 스토리 ↔ 퀘스트 ↔ 콘텐츠
- [OPEN] 각 주요 스토리 전환점은 어떤 플레이 가능한 행동으로 전달되는가?
- [OPEN] 퀘스트 목표·조건·실패·완료 결과가 전체 서사의 인과관계를 보존하는가?
- [OPEN] 반복 콘텐츠가 시간상 이미 끝난 사건을 무한 반복하는 모순을 어떻게 피하는가?
- [OPEN] 보스·지역·이벤트·적 세력의 배치가 스토리 진행과 어떻게 연결되는가?
- [OPEN] 컷신이나 대사만으로 처리할 사건과 플레이어가 직접 수행해야 할 사건을 구분하는 기준은 무엇인가?

## D. 게임플레이 ↔ 장비·성장·루팅
- [OPEN] 핵심 루프의 각 단계에서 장비·자원·성장이 어떤 역할을 하는가?
- [OPEN] 전투·탐색·임무 목표가 보상 테이블과 어떻게 연결되는가?
- [OPEN] 빌드 다양성이 핵심 전투 역할과 어떤 관계를 갖는가?
- [OPEN] 장비 파밍과 서사 진행이 서로를 불필요하게 차단하지 않도록 어떤 경계가 필요한가?
- [OPEN] 보상 획득·장착·개조·분해·저장·교환 등 행위의 소유 파트와 연결 파트는 누구인가?
- [OPEN] 밸런스 조정이 세계관 설명이나 스토리 연출을 바꿔야 하는 경우의 검토 절차는 무엇인가?

## E. 게임플레이 ↔ 동료·NPC·세력
- [OPEN] 동료와 의병이 플레이어에게 제공하는 전투·정보·탐색·거점 기능은 무엇인가?
- [OPEN] NPC의 생사·부재·세력 이동이 퀘스트와 지역 상태에 미치는 영향은 무엇인가?
- [OPEN] 세력 신뢰·적대·협력 상태가 대사, 상점, 임무, 전투에 어떻게 반영되는가?
- [OPEN] 동료가 임무에 참여할 수 없을 때 대체 흐름은 무엇인가?
- [OPEN] NPC 반응을 바꾸는 상태의 단일 출처는 어디인가?

## F. 세계 ↔ 이동 ↔ 임무 접근성
- [OPEN] 지역 해방, 이동 제한, 축지, 차단 장치가 월드 탐색과 퀘스트 진행에 어떤 공통 조건을 제공하는가?
- [OPEN] 임무 시작·탈출·재진입 조건과 세계 상태는 어떻게 연결되는가?
- [OPEN] 플레이어가 목표 지역에 너무 일찍 도착하거나 우회 경로를 찾았을 때 어떤 규칙이 적용되는가?
- [OPEN] 지역 차단이 세계관상 이유인지, 진행 제어인지, 난이도 제어인지 어떻게 구분할 것인가?
- [OPEN] 이동 수단이 바뀌었을 때 기존 콘텐츠의 접근성·동선·전투 공간을 재검토하는 기준은 무엇인가?

## G. 정보·자원·경제·공동체
- [OPEN] 자원 수탈, 보급, 제작, 장비 성장, 활빈당 운영이 어떤 인과관계로 연결되는가?
- [OPEN] 플레이어가 확보한 정보가 스토리 진행·세력 대응·퀘스트 선택에 어떤 영향을 주는가?
- [OPEN] 지역 자원이나 보급로를 확보·상실하면 어느 시스템이 영향을 받는가?
- [OPEN] 경제·보상 수치와 세계관상 자원 희소성 사이에 지켜야 할 원칙은 무엇인가?
- [OPEN] 플레이어 개인의 소지품과 공동체 자산은 어떻게 구분되는가?

## H. UI/UX·피드백·오디오/연출
- [OPEN] 공통 상태 변화가 플레이어에게 알려져야 하는 최소 정보는 무엇인가?
- [OPEN] 같은 시스템 상태를 HUD, 지도, 대사, 시각 효과가 서로 다르게 표현하지 않도록 기준을 어떻게 정할 것인가?
- [OPEN] 중요한 선택·실패·보상·지역 변화의 피드백은 어떤 정보를 반드시 전달해야 하는가?
- [OPEN] 세계관 설명을 위해 필요한 연출과 플레이어가 실제로 알아야 하는 시스템 정보를 어떻게 구분할 것인가?
- [OPEN] 접근성·가독성·언어 현지화가 공통 용어와 UI 문구에 어떤 제약을 주는가?

## I. 변경 영향과 인터페이스 기록
- [OPEN] 공통 인터페이스를 바꾸면 어떤 영역에 영향이 있는지 기록하는 표준 형식은 무엇인가?
- [OPEN] 각 인터페이스에 입력, 출력, 전제, 성공 조건, 실패 조건, 상태 변화, 예외, 담당자를 기록할 것인가?
- [OPEN] 상위 규칙 변경으로 기존 파트 기획이 무효화될 경우 영향 분석과 재검토 순서는 무엇인가?
- [OPEN] 인터페이스를 검수할 대표 시나리오와 테스트 사례는 무엇인가?
- [OPEN] 어떤 연결은 공통 기획에서 확정해야 하고 어떤 연결은 세부 파트 기획에서 정해도 되는가?

## 완료 판단
- 핵심 파트 경계와 산출물 소유자가 명시되어 있다.
- 핵심 의존성에 입력·출력·조건·상태 변화·실패 흐름이 기록되어 있다.
- 교차 영역 변경의 영향과 검수 담당을 추적할 수 있다.
- 최소한의 대표 시나리오로 파트 간 연결을 검증할 수 있다.
