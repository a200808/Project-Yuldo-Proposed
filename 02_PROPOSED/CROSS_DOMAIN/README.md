# CROSS DOMAIN PROPOSALS

두 개 이상의 담당 영역에 걸치는 제안을 기록한다. 관련 AI들의 의견을 함께 연결하고 REVIEW 대상으로 관리한다. [PROPOSED]

## 공통 기획 질문지 묶음

아래 문서는 공통 기획을 위한 질문지 세트다. 모두 Proposed이며, 질문에 답했다고 자동으로 Confirmed가 되지 않는다. 기존 Confirmed 문서에 답이 있으면 재결정하지 말고 출처를 연결한다. 사용자 승인 전까지 Canon은 변경하지 않는다.

1. [P] [공통 기획 기반 질문지](P_COMMON_FOUNDATION_QUESTIONS.md) — 게임의 정체성, 핵심 루프, 세계관 전제, 전체 서사 방향, 플레이어/활빈당 역할, 성장·보상 목적, 범위, 소유권, 세션 분리 조건.
2. [P] [공통 규칙·용어·상태 정의 질문지](P_COMMON_RULES_AND_TERMS_QUESTIONS.md) — 공식 용어, 세계관의 가능·불가능, 공통 상태, 상태 변화, 우선순위, 예외, 근거 추적.
3. [P] [파트 간 연결·의존성 질문지](P_CROSS_DOMAIN_INTERFACES_QUESTIONS.md) — 영역 경계, 입력·출력, 교차 시스템 연결, 변경 영향, 실패 흐름, 책임 소유권.
4. [P] [플레이어 경험·대표 시나리오 검증 질문지](P_PLAYER_EXPERIENCE_VALIDATION_QUESTIONS.md) — Player View/System Logic, 대표 플레이 상황, 예외 흐름, 서로 다른 담당자의 결과 일치 여부.
5. [P] [공통 범위·결정·인계 질문지](P_COMMON_SCOPE_DECISION_AND_HANDOFF_QUESTIONS.md) — 의사결정 분류, 논의 범위 통제, 승인·REVIEW·버전 기록, 전문 세션 인계, 공통 기획 종료 조건.

## 권장 사용 순서

1. 공통 기획 기반 질문지에서 상위 방향과 선행 결정을 식별한다.
2. 공통 규칙·용어 질문지로 여러 파트가 공유해야 할 정의와 규칙의 공백을 찾는다.
3. 파트 간 연결·의존성 질문지로 영역별 책임과 인터페이스를 정리한다.
4. 대표 시나리오 질문지로 같은 게임을 예상하는지 검증하고, 불일치를 앞선 질문으로 되돌린다.
5. 범위·결정·인계 질문지로 미결정 사항, 승인 필요 항목, 담당 세션, 다음 단계 진입 조건을 정리한다.

이 순서는 제안이며 공식 Phase 변경이나 Canon 확정을 의미하지 않는다. 프로젝트 상태와 공식 로드맵을 우선한다. 세부 무기·개별 퀘스트·수치·구현 명세는 공통 질문에 답하는 데 꼭 필요하지 않다면 해당 전문 파트로 이관한다.
