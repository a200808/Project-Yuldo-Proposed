# 대화 기록 운영 규칙

상태: [PROPOSED]

## 목적

프로젝트 율도의 중요한 기획 대화를 장기 보존한다.

대화 기록은 Canon이 아니다. 대화 중 AI가 잘못 제안했거나 사용자가 이후 철회한 내용도 원문 기록으로 남을 수 있다.

## 기록 대상

모든 대화를 무조건 저장하지 않는다. 다음과 같이 장기적으로 가치가 있는 대화를 우선 기록한다.

- 새로운 핵심 아이디어가 나온 대화
- 기존 설정이 변경되거나 폐기된 과정
- 사용자와 AI의 의견이 충돌한 과정
- 중요한 대안과 반대 의견
- REVIEW가 필요했던 문제
- 최종 결정의 배경이 된 논의
- 시스템의 원인/결과/예외 규칙을 정의한 대화
- 이후 다른 AI가 같은 판단을 재현하는 데 도움이 되는 대화

## 권장 파일명

`YYYY-MM-DD_<AI ROLE>_<TOPIC>.md`

예:
- `2026-09-11_STORY_HONG_GILDONG.md`
- `2026-09-11_QUEST_CHRONOS_NAMING.md`

## 대화 기록 메타데이터

각 기록에는 가능하면 다음을 포함한다.

- Conversation ID
- Session ID
- 작성/담당 AI
- AI Role
- Prompt Version
- 날짜
- 관련 Phase
- 관련 영역
- 관련 Confirmed 문서
- 관련 Proposed 문서
- 최종 결정 여부

## 중요한 원칙

1. 대화 원문과 공식 설정을 구분한다.
2. 대화에서 나온 제안은 승인 전까지 [PROPOSED]다.
3. 사용자가 철회한 내용도 필요하면 기록으로 보존하되 폐기/철회 상태를 명확히 표시한다.
4. 대화 기록을 근거로 Confirmed를 임의 변경하지 않는다.
5. 최종 결정에 중요한 대화는 Decision Record와 연결한다.

## 활용

대화 기록은 다음 목적으로 사용한다.

- 왜 현재 설정이 되었는지 추적
- 과거에 검토했던 대안 재확인
- AI의 판단 오류 확인
- AI 교육용 사례 추출
- 결정 기록의 근거 보존

대화 기록 자체를 매번 모든 AI가 전부 읽는 것은 기본값으로 하지 않는다. 현재 작업과 관련된 기록을 선택적으로 조회한다.
