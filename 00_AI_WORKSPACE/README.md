# AI WORKSPACE

프로젝트 율도의 브레인스토밍 및 제안 작업장을 운영하기 위한 규칙과 구조를 정의한다.

이 저장소의 내용은 브레인스토밍 기간 동안 [PROPOSED] 상태로 취급한다. 사용자의 최종 승인 전에는 공식 Canon으로 간주하지 않는다.

## 기본 원칙

- Confirmed 저장소는 모든 AI가 읽고 참고해야 한다.
- Proposed 저장소는 모든 AI가 읽을 수 있어야 한다.
- AI는 Confirmed를 임의로 수정하거나 승격하지 않는다.
- 사용자 승인 전의 내용은 Proposed에만 축적한다.
- 담당 AI의 원문은 다른 AI가 덮어쓰지 않는다.
- 다른 AI가 대안·수정·이의를 제기할 경우 `other_ai_proposed`에 독립 문서로 기록한다.
- 모든 작업 문서는 작성 AI, 역할, Prompt Version, 문서 ID, 작성일 등을 명시한다.
- 브레인스토밍 종료 후 REVIEW를 거쳐 사용자가 승인한 내용만 Confirmed로 이관한다.
